# Business sites + Business Hub app

Free static site hosted on GitHub Pages.

| Path | What |
|---|---|
| `/` | NRI parent care landing page |
| `/checklist.html` | Free Parent Safety Checklist (lead magnet) |
| `/weddings/` | Wedding website studio page |
| `/weddings/demo-royal/`, `/weddings/demo-coastal/` | Live demo wedding sites |
| `/app/` | Business Hub: installable app for leads, NRI clients, weddings, RSVPs and payments (data stays on your device) |

**To change your name, city, WhatsApp, UPI or brand names, edit `config.js` only.**

For a new wedding client: copy `weddings/demo-royal/` to `weddings/<couple-name>/` and edit its `data.js`.
